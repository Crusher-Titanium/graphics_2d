# graphics_2d (v1.0.1)

2d graphics around turtle

## Usage Example

```python
import graphics_2d

window = graphics_2d.Window()
window.draw_dot(100, 50) #x1, y1
window.draw_dot(125, 25) #x2, y2
window.draw_dot(110, 75) #x3, y3
window.draw_triangle(100, 50, 125, 25, 110, 75)
window.show()
```
